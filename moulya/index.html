PROJECT CASE STUDY

Smart IoT-Based Water Quality & Turbidity Monitoring System

Overview

An integrated Internet-of-Things embedded solution designed to continuously measure the optical clarity of water, detect turbidity changes in real-time, render instant physical alerts, and transmit telemetry data to a cloud database for remote mobile inspection.

Problem Statement

Traditional water quality testing frequently relies on manual sample collection and lab-based testing. This leads to latency in detecting contamination events in residential, industrial, and agricultural supplies where real-time turbidity alerts are essential.

Objective

  • Accurately measure water turbidity levels through an analog optical turbidity sensor.
  • Provide immediate localized feedback via a 16x2 I2C LCD character display.
  • Deliver intuitive status signaling through RGB LED color transitions and an audio alert buzzer.
  • Securely push sensory JSON payloads to Google Firebase Realtime Database using Wi-Fi.
  • Provide a user-friendly mobile monitoring interface built in MIT App Inventor.

Technology & Components Architecture

Hardware Components

  • Microcontroller: ESP8266-12F (NodeMCU)
  • Sensor: Optical Turbidity Sensor
  • Display: 16x2 Character LCD (I2C)
  • Visual Alert: Common-Cathode RGB LED
  • Auditory Alert: Active Piezo Buzzer

Software & Cloud Components

  • IDE: Arduino IDE (C++ Firmware)
  • Cloud DB: Firebase Realtime Database
  • Mobile App: MIT App Inventor (Android)
  • Data Format: JSON REST Telemetry
  • Protocol: HTTP/REST over Wi-Fi (802.11 b/g/n)

System Workflow Pipeline

1 Turbidity Sensor measures analog voltage corresponding to light transmittance through water sample.
2 ESP8266 ADC reads the input, converts voltage into NTU / threshold levels, and updates 16x2 LCD.
3 Threshold triggers set RGB LED (Green = Normal, Yellow = Moderate, Red = Critical) & Buzzer if dirty.
4 Payload is synced with Firebase Realtime Database, which triggers live UI updates in the Android Mobile App.

Key Challenges

Calibrating analog sensor noise, managing ESP8266 single ADC channel limitations, and synchronizing asynchronous Firebase JSON responses.

Learning Outcomes

Mastered I2C communication protocols, microcontroller Wi-Fi state handling, cloud database integration, and mobile UI/UX event routing.

Future Roadmap

Integrating pH and TDS multi-sensor arrays, edge anomaly classification, solar power scavenging, and automated push notification webhooks.
